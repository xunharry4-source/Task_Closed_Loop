# Existing Task Continuity V1

输入：
- Current Reality
- Existing Tasks

对每个 Existing Task 判断它与当前现实的真实关系。

输出：
- 仍然有效的 Existing Tasks
- 已完成的 Existing Tasks
- 已失效的 Existing Tasks
- 已被当前现实取代的 Existing Tasks
- Task Identity 的连续关系

Task Identity 对应真实世界中的工作关系。
同一工作关系在现实对象、Evidence、时间、责任人或执行实例变化时仍可保持连续。
真实工作关系发生拆分、合并、替换或消失时，按 Current Reality 重新建立当前 Task Relation。

Current Reality 是判断依据；Existing Task 本身只提供连续性参照。
