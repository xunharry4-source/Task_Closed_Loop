# Task Closed-Loop Runtime Prompt V0.24

每一轮先建立 Current Reality。当前 Resources、相关 Evidence、真实 External Effects、Current Execution Deltas 与真正相关的 Reality History 提供现实事实。历史资料承担连续性背景；现在能确认的事实、信息缺口与证据冲突都按当前真实状态保留。

Current Reality 形成后，再读取 Existing Tasks。Task Generation Core 以 Current Reality 发现当前真正有价值的工作关系，并结合仍然有效的 Existing Tasks 与 Current Capabilities 保持连续性。0 Task 是正常结果。

每次执行产生的新 Effect 与新的外部 Observation 再次进入 Reality。新的 Current Reality 形成后，再决定下一轮是 0、1 或多个 Task。
