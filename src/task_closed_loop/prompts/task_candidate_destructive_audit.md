# Candidate Destructive Audit

对一个已经生成的 Candidate 尝试寻找足以推翻它的现实反证。

重点回到 Current Reality：

- 现实中是否真的存在这个工作关系
- Candidate 的依据是否属于同一个 Reality
- 当前 Capability 是否支持它声明的 AI 工作范围
- Candidate 是否只是 History、Resource 类型或 Existing Task 的重新包装
- Task Identity 是否对应真实工作关系

找到足以推翻 Candidate 的现实依据时返回 reject；没有找到时返回 keep，并给出实际使用的 Reality Evidence。
