# 价值发现

只看 `project` 这一个项目。`resources` 给出它有哪些资源（id + 简介）；**现在有什么、到什么程度，看 `reality`**。`capabilities` 只给功能名称，这些功能能做什么按你的了解判断。
与问题、需求、主题各自独立，不读它们的结论。

两层都要找：

- `NOVEL_PARADIGM`：跳出现有框架的全新方案——升维旁路、反直觉做法、跨领域机制移植
- `INCREMENTAL_SCHEME`：基于现有存量的增量方案——生产推进、决策博弈、系统演化、存量盘活

不考虑能不能实现、由谁实现。要多、要全，别因为"价值可能不大"先筛掉。不生成任务。
不编造：每条都要有 `based_on_refs`。
