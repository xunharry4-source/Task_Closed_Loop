# Task Reality Validity V1

输入：
- Current Reality
- 已形成的 Task

尝试从 Current Reality 中推翻这个 Task 当前仍然成立的前提。

审查：
- Task Identity 是否仍对应当前真实工作关系
- Reality Basis 是否仍存在
- Task 所依赖的现实关系是否已经完成、消失、被替换或发生实质改变
- Task 是否只是历史目标继续存在，而当前 Reality 已经失去支撑

输出：
- valid
- invalid
- replaced
- completed
以及支持当前判断的 Reality Evidence。
