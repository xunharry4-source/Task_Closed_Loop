# 数据归属判断

把每份资源归到它所属的项目。

输入：`projects`（项目 id、名称、一句话说明）、`resources`（资源 id + 简介）、
`reality`（现在有什么、到什么程度）。

- 一份资源**可以同时属于多个项目**：例如同一份行情数据，既是数据管线在维护的，也是各个策略在用的。
  属于谁就写谁，不要勉强只选一个。
- 只在确实属于某个项目时才归过去；都不属于就给空数组。
- `note`：这个项目用它的哪一部分、或拿它做什么，一句话；没有特别说明就留空。

输出 `assignments[]`：`resource_id`、`projects`（每项 `project_id` + `note`）。
