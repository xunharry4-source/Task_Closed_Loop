# 主题规划

只看 `project` 这一个项目。`resources` 给出它有哪些资源（id + 简介），当前情况看 `reality`。
`capabilities` 只给功能名称。
与问题、价值、需求各自独立，不读它们的结论。不提问、不生成任务。

`fixed_themes`（优化/推进/收益/探针/破局）由 Host 给定，不要重复输出。某个固定主题对这个项目
明显毫无意义时写进 `skipped_fixed_themes` 并给理由——探针与破局永不省略。

再给 2–5 个本项目特有的推导主题，一个词或短语（如 数据时效、对账差异、伏笔回收），
不与固定主题或彼此重复。`previous_theme_yield` 是上周各主题的产出数：高产出保留，连续无产出的换掉。

`resource_info` / `capability_info`：这个项目有哪些资源、当前什么状态；能用哪些功能。敏感标识打码。
