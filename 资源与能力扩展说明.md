# 资源与能力扩展说明

整个项目只需要记住两个入口。

# 一、测试 Resource / Capability

修改：

```text
config/test_resources.yml + config/test_capabilities.yml
```

运行：

```text
test_runtime.py
```

例如：

```yaml
test:

  resources:
    - id: server-01
      type: server_status
      fact: production server disk usage reached 95%

  capabilities:
    - id: ticket.create
      description: create an incident ticket
      action_type: create_ticket
```

详细见：

```text
测试Resource与Capability配置说明.md
```

---

# 二、真实 Gmail / 数据库 / 服务器 / 第三方系统

修改：

```text
config/mcp_servers.yml
```

添加 MCP Server。

系统自动映射：

```text
MCP resources → Resource
MCP tools     → Capability
```

不需要为每个系统重新编写 Python Adapter。

详细见：

```text
MCP外部系统接入说明.md
```

---

# 三、高级兼容入口

只有目标系统没有 MCP Server 时，才需要自定义：

```text
src/task_closed_loop/adapters/<provider>.py
```

然后在：

```text
config/providers.yml
```

注册。

这是高级扩展路径，不是普通开发流程。
